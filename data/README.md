# Data

This project uses the Coffee Quality Institute (CQI) Arabica dataset (1,311 samples).

Download `arabica_data_cleaned.csv` from Kaggle and place it in this folder before running the scripts:

https://www.kaggle.com/datasets/volpatto/coffee-quality-database-from-cqi

The raw CSV is not committed to this repo to keep it lightweight - add it locally, or wire up `data/` in `.gitignore` removal if you'd like to version it.
